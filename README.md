## Your Web Application Title
This is my attempt at a recipe pinner, a website where you could theoretically
save a variety of online recipes from other pages. 

## Technical Achievements
- **Responsive, Always Active Form**: My webpage has a form for submitting recipes that always displays the most up to date info from the backend. This
includes on refresh, on update, and on delete.
- **Modification to existing data**: Each saved recipe has an edit button that allows the changing of data in the database. The form auto-populates with the data currently in the database for the editing entry, and the button text updates alongside it.

### Design/Evaluation Achievements
- **UX Testing**: Accomplished with Patrick Tirch and William Hanlon fron this class. Participants were asked to save, edit, and delete a recipe. Feedback from each was as follows.

1. Patrick Tirch
2. The webpage broke down when he attempted to enter in an autofilled link that I was using for testing (http://). The domain field couldn't be properly derived.
3. He was unsure where the recipes would appear after he saved them, in addition, he wasn't sure what the domain field was.
4. I think I need to add a fixed, always visibile box around where the recipes usually appear, and I need to label the fields better.

1. William Hanlon
2. No direct problems were encountered during the completion of the task. Comments were made regarding the visual appeal of the design however.
3. He was a fan of neither the font nor the color pallette used for the webpage, and pointed out the edit and delete buttons looked out of place.
4. I think I might need to go and use an actual font instead of comic sans. Coloring might also require taking a look at.
